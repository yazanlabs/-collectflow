# CollectFlow MVP

A lightweight browser-based prototype for prioritizing overdue invoices and drafting collection follow-ups.

## Run
Open `index.html` in a browser.

## CSV columns
`customer,email,invoice,due_date,amount`

## Current prototype features
- CSV import
- Overdue metrics
- Priority scoring
- Suggested follow-up stage
- Editable collection message
- Approve / Skip workflow

This is a prototype only. It does not send emails or store real customer data yet.
